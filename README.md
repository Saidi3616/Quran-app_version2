# Quran-app (version 2)

En web-app (PWA) til at læse Quran på arabisk, lytte til recitation og gemme bogmærker.

Projektet bygges med **Spec-Driven Development (SDD)**: vi skriver først *hvad* appen skal
kunne (specifikationen) og bygger derefter koden ud fra den. Start med at læse
[`specs/README.md`](specs/README.md).
